Set up the OpenAI API key

Export OPENAI_API_KEY in the environment that starts mflux-web. For a terminal launch, you can add export OPENAI_API_KEY="your-api-key" to ~/.zshrc, open a new terminal, and restart mflux-web there.

The Web UI inherits the exported variable; it does not read or execute shell configuration files. A background service needs the key configured in its own launch environment.

Keep the key outside this repository. No key is entered or stored in this page. Key detection does not verify billing or model access.

Set up Hugging Face access

Public, ungated models usually work without a token. Gated or private downloads need a token with access to that model; gated models may also require accepting terms on their model page.

  1. On the machine running mflux, under the same user account, run hf auth login and follow the prompts.
  2. If hf is unavailable, run uvx --from huggingface-hub hf auth login.
  3. Return here and choose Refresh status.

Alternatively, set HF_TOKEN in the environment that launches mflux, then restart the server. An environment token takes precedence over a saved login.
